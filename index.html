Questions

Where does the data come from?

From your public GitHub contribution calendar, the same one on your profile. No sign-in is needed to try it.

Are private contributions included?

Only if you've turned on "Include private contributions" on your GitHub profile. Then they're counted, without any details.

Will my README image stay up to date?

Yes. It's redrawn from your latest contributions and refreshed about once an hour.

How does Pro work with my embeds?

Pro is linked to your GitHub username. Once you upgrade, every embed and README image for your profile unlocks automatically. There are no keys to paste.
